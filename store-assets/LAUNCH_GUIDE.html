📋 Your Steps — In Order
1
Create Expo Account & Run EAS Login
Free · 5 minutes · Required for cloud builds
Free
ℹ️ EAS (Expo Application Services) builds your app in the cloud — no Android Studio or Xcode needed on your machine.

1. Create your free account, then come back and run the login command.

🔗 Create Expo Account

2. After creating your account, open the PowerShell terminal that just appeared on your screen and run:

eas login

3. Enter your email and password when prompted. Then verify:

eas whoami
2
Set Up Firebase (Push Notifications)
Free · 15 minutes · Required for push notifications
Free
⚠️ Without Firebase, push notifications will not work. Firebase is free for your usage level.

Follow the FIREBASE_SETUP_GUIDE.md in your project root. Key steps:

  • Go to console.firebase.google.com → Create project "alumni-network"
  • Add Android app (package: com.mediacell.alumni) → Download google-services.json
  • Replace the template google-services.json in your project root with the downloaded file
  • Add iOS app (bundle ID: com.mediacell.alumni) → Download GoogleService-Info.plist
  • Replace the template GoogleService-Info.plist in your project root with the downloaded file
🔗 Open Firebase Console
3
Link EAS to Your Project
Free · 2 minutes · Do after Step 1
Free

Run this in your project terminal after logging in to EAS:

eas init

This creates your EAS project and fills the projectId in your config automatically. When asked, select Create a new project and name it alumni-network.

4
Build Android Production AAB
Free · ~20 min cloud build · Produces Play Store file
Free
✅ EAS builds the .aab file in the cloud. You do NOT need Android Studio installed. The build happens on Expo's servers.

Run this command (after Steps 1–3 are complete):

npm run build:android

When it finishes (~15–20 min), download the .aab file from:

🔗 expo.dev → Your Project → Builds
5
Create Google Play Developer Account
$25 one-time fee · 15 minutes
$25
💳 This is a one-time $25 registration fee — you only pay this once ever, not per app or per year.

Steps:

  • Click the button below → Sign in with your Google account
  • Fill developer profile (name: RV Educational Institutions, email: rvmediadevelopers@gmail.com)
  • Pay $25 via credit/debit card
  • Account is usually approved instantly
🔗 Open Play Console Signup
6
Create App & Upload to Play Console
Free · 30 minutes · After Step 5
Required

In Play Console after account is approved:

  • Create app → Name: Alumni Network → Free
  • Store listing → Use content from STORE_SUBMISSION_GUIDE.md
  • Short description: "Connect with RV alumni. Network, jobs, mentors & events."
  • Privacy policy URL: Paste below ↓
https://github.com/HarshithaDS631/alma/blob/main/PRIVACY_POLICY.md
  • Release → Internal testing → Upload the .aab from Step 4
  • Age rating: Teen (13+) · Data safety: fill from STORE_SUBMISSION_GUIDE.md
7
Test Internally → Submit for Review
Free · 1–7 days review time
Required
ℹ️ Google reviews new apps within 1–7 days. Test on Internal Testing track first (instant), then promote to Production.
  • Add your own Gmail as an internal tester
  • Install the app on your Android phone via the testing link
  • Test all features: login, profile, jobs, chat, notifications
  • When satisfied → Production → Create release → Submit for review
🍎 Apple App Store (Optional / Later)
8
Create Apple Developer Account
$99/year · 30 minutes + verification time
$99/yr
⚠️ Apple requires $99/year. Apple also manually reviews every app which can take 1–3 days. Skip this for now and launch on Play Store first.
🔗 Apple Developer Enrollment 🔗 App Store Connect

After account approval, run:

npm run build:ios
